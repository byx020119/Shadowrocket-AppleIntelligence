# Shadowrocket Apple Intelligence

本仓库用于在中国大陆网络下，通过 Shadowrocket 把 Apple Intelligence 相关流量走代理，从而打开 **Apple Intelligence 的 ChatGPT 扩展**（同时覆盖 Siri / Private Cloud Compute 所需域名）。

每天自动基于白名单+去广告规则叠加 AI 域名后发布。使用时建议连接 **美国或新加坡** 节点。

## 导入地址

```
https://raw.githubusercontent.com/byx020119/Shadowrocket-AppleIntelligence/main/sr_top500_whitelist_ad_appleintelligence.conf
```

小火箭：配置 → **+→ 从 URL 下载** → 粘贴上方链接 → **使用配置**。  
配置 → ⓘ → 通用 → 打开 **自动后台更新**。
